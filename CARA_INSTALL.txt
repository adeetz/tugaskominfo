================================================================================
CARA INSTALL - SISTEM MANAJEMEN PENGGUNA
Tugas Kominfo - Aplikasi Manajemen User (Bahasa Indonesia)
================================================================================

PERSYARATAN SISTEM:
- PHP 8.0 atau lebih tinggi
- MySQL 5.7 atau MariaDB 10.2 atau lebih tinggi
- Web Server (Apache/Nginx)
- Browser modern (Chrome, Firefox, Edge, Safari)

================================================================================
LANGKAH INSTALASI (7 MENIT):
================================================================================

1. EXTRACT PROJECT
   - Extract file ZIP ke folder web server
   - Contoh: C:\laragon\www\tugaskominfo
   - Atau: /var/www/html/tugaskominfo

2. BUAT DATABASE
   - Buka tool database (Adminer/phpMyAdmin/HeidiSQL)
   - Buat database baru dengan nama: tugaskominfo
   - Collation: utf8mb4_unicode_ci (atau utf8mb4_general_ci)

3. IMPORT DATABASE UTAMA
   - Pilih database "tugaskominfo"
   - Klik menu Import atau SQL Command
   - Pilih file: database.sql
   - Klik Execute/Go
   - Tunggu sampai selesai

4. IMPORT TABEL SETTINGS (BARU!)
   - Tetap di database "tugaskominfo"
   - Klik menu SQL Command
   - Pilih file: database_update.sql
   - Klik Execute/Go
   - Tunggu sampai selesai
   
   CATATAN:
   Tabel 'settings' diperlukan untuk fitur upload logo login.
   Jangan skip langkah ini!

5. JALANKAN SETUP (PENTING!)
   - Buka browser
   - Akses: http://localhost/tugaskominfo/setup.php
   - Klik tombol "Run Setup Now"
   - Tunggu sampai muncul "Setup Complete!"

   CATATAN PENTING:
   Setup.php akan otomatis generate password hash yang kompatibel 
   dengan versi PHP di komputer Anda. Ini memastikan login pasti berhasil
   tanpa masalah compatibility.

6. LOGIN
   - Klik tombol "Go to Login Page"
   - Atau akses: http://localhost/tugaskominfo/login.php
   
   Kredensial Default:
   Email    : admin@example.com
   Password : Admin@123

7. UPLOAD LOGO (OPSIONAL)
   - Setelah login → Klik dropdown email di navbar
   - Pilih menu "Pengaturan"
   - Upload logo custom untuk halaman login
   - Format: PNG, JPG, SVG, GIF, WebP
   - Maksimal: 2MB

8. SELESAI!
   - Aplikasi siap digunakan
   - PENTING: Ganti password default setelah login pertama!
   - Test responsive: Mobile, Tablet, Laptop

================================================================================
TROUBLESHOOTING:
================================================================================

Problem: "Database connection failed"
Solusi: 
- Pastikan MySQL berjalan
- Edit file config/database.php, sesuaikan kredensial database
- Pastikan nama database sudah dibuat

Problem: "Cannot login"
Solusi:
- Jalankan setup.php lagi
- Setup.php akan reset password dengan hash yang benar

Problem: "Page not found / 404"
Solusi:
- Pastikan semua file sudah ter-extract
- Pastikan web server berjalan
- Cek URL: http://localhost/tugaskominfo

Problem: Halaman blank putih
Solusi:
- Cek PHP version minimal 8.0
- Aktifkan error reporting di php.ini
- Cek error log Apache/Nginx
